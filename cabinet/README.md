# Fast-Bot — обычный статический сайт

Это готовая версия без React, Vite, Node.js, модулей, CDN и внешних библиотек.
Архив можно распаковать и открыть двойным кликом файл `index.html`.

## Страницы

- `index.html` — обзор заявок
- `new/index.html` — новая заявка
- `settings/index.html` — настройки
- `application.html?id=...` — отдельная заполненная заявка

После последнего шага конструктора открывается `application.html` с данными
созданной заявки. На этой странице работают попап выбора оплаты и попап
подтверждения отмены.

Все пути внутри сайта относительные. Можно загрузить содержимое этой папки в
корень репозитория GitHub Pages или на любой обычный статический хостинг.
