# Booking Ops — UI-прототип (Tabler, без бэкенда)

Кликабельный прототип панели оператора. Чистые HTML-страницы, Tabler через CDN,
никакой сборки — просто открыть в браузере или залить в GitHub Pages.

## Как посмотреть

- Локально: открыть `index.html` в браузере (ссылки между страницами рабочие).
- GitHub Pages: Settings → Pages → Deploy from branch → `main` / `/ (root)`.

## Структура

```
assets/
  style.css       — оверрайды поверх Tabler: демо-плашки, skeleton, статус-точки
  mock-data.js     — единый источник фейковых данных (клиенты, события, очередь, мониторинг)
  layout.js        — рисует сайдбар и топбар на каждой странице (правки навигации — тут)
index.html         — Дашборд / Operations Center
```

Все виджеты, которые в проде будут живыми (счётчики, очередь, статус мониторинга),
помечены плашкой «демо-данные · в проде — с бэкенда через WS» и грузятся с
имитацией сетевой задержки (skeleton → рендер), чтобы сразу было видно, где
подключится реальный бэкенд.
