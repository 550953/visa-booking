# Booking Ops — автономная HTML-версия

Эта папка открывается без npm, Node.js, Vite, React и сборки.

## Как открыть

1. Распакуйте папку.
2. Откройте `index.html` двойным кликом.
3. Переходы между разделами работают через обычные файлы: `queue.html`, `customers.html`, `monitoring.html` и другие.

Папку также можно загрузить в GitHub Pages или любой статический хостинг. Для GitHub Pages выберите публикацию из корня репозитория.

## Важно

Это локальный демонстрационный контур: данные находятся в `app.js`, а настройки переключателей сохраняются в браузере. Для подключения реальных заявок и пользователей потребуется отдельный сервер.
